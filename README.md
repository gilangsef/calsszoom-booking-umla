## 🎓 SIM CLASS UMLA

**SIM CLASS UMLA** (Sistem Informasi Manajemen Kelas) is a comprehensive web-based application designed to streamline the booking and management of physical classrooms and virtual meetings. 

Built with a focus on modern UI/UX and efficient administration, this system ensures smooth coordination for academic scheduling, utilizing generated Zoom links for seamless virtual class integrations and QR Codes for physical room verification.

### ✨ Key Features

- **Room & Virtual Class Booking:** Easy-to-use interface for scheduling physical rooms and online sessions.
- **Generated Zoom Links:** Supports direct input of generated Zoom meeting links for virtual classes, eliminating the need for complex API integrations.
- **QR Code Verification:** Integrated QR code system for quick and secure room booking verification.
- **Role-Based Access Control:** Distinct dashboards and permissions for different user roles (Admin, Lecturers, Students).
- **Modern Dashboard:** Powered by Filament PHP for a clean, responsive, and powerful administrative experience.

---

## 💻 Tech Stack

- **Backend:** [Laravel 12](https://laravel.com)
- **Admin Panel:** [Filament PHP](https://filamentphp.com)
- **Frontend / Styling:** [Tailwind CSS 4](https://tailwindcss.com)
- **Database:** [MySQL](https://www.mysql.com)
